# ЯДРО-2026 — программа конференции

Интерактивное расписание (русский / English) для сайта [nucleus.togudv.ru](http://nucleus.togudv.ru/). Работает без сервера: достаточно открыть папку `site/` в браузере или отдать администратору один HTML-файл.

## Что смотреть участникам

- `site/index.html` — полноценный сайт (откройте файл двойным щелчком или положите всю папку `site/` на веб-сервер).
- `dist/nucleus2026-programme.html` — тот же сайт одним файлом (удобно переслать или вставить на WordPress через iframe). Собирается командой ниже.

## Как устроена правка программы

Единственный источник правды — книга **`data/programme.xlsx`**. Сетка «TimeTable» из исходного Excel больше не редактируется: расписание на сайте **собирается** из списков докладов и блоков.

Исходная книга комитета лежит в `data/original/` (архив) и в корне репозитория.

```
data/programme.xlsx  →  python tools/build.py  →  site/data.js
                                               →  dist/nucleus2026-programme.html
```

После любой правки книги:

```text
python tools/build.py
```

Обновите страницу в браузере. Если Excel держит файл открытым, сборка напишет об этом — сохраните и закройте книгу.

Проверка без записи файлов: `python tools/build.py --check`.

Нужны Python 3.10+ и пакет `openpyxl` (`pip install openpyxl`). Node.js и conda не требуются.

## Листы `programme.xlsx`

Заголовки столбцов не переименовывайте. Строки можно добавлять, удалять и переставлять. Пустая английская ячейка на сайте подменяется русской (и наоборот).

### Настройки

Название конференции, город, даты, часовой пояс (`Asia/Vladivostok`), смещение UTC (`+10:00`), ссылка на сайт, контакт, сноска под расписанием.

### Секции

Номер (`1`–`7`, `P` — пленарные), краткое и полное название RU/EN, председатель заседания (пока «уточняется»; не путать с ответственным за секцию — см. `data/inconsistencies.md`), цвет (`blue`, `green`, `orange`, `red`, `purple`, `teal`, `pink`, `slate`), аудитория по умолчанию (пока пусто).

### Блоки

Одна строка — один слот расписания.

| Столбец | Что писать |
|---|---|
| Дата | `21.09.2026` или `2026-09-21` |
| Начало / Конец | `16:15` |
| Тип | только из списка: `пленарный`, `юбилейный`, `спонсор`, `секция`, `перерыв`, `обед`, `регистрация`, `открытие`, `закрытие`, `постеры`, `мероприятие` |
| Название (RU) / (EN) | для кофе и обеда можно оставить пустым — подставятся стандартные подписи |
| Секция | `1`–`7` или `P` |
| Доклады | диапазон `8-14`, одно число `12`, юбилей `Ю1`, спонсор `С2`, список `1,3,5` |
| Аудитория | необязательно; иначе берётся из листа «Секции» |
| Примечание | RU/EN |

Время каждого доклада внутри секции считается автоматически: начало блока + сумма длительностей предыдущих. Чтобы сдвинуть один доклад, заполните столбец «Начало» в листе «Доклады».

### Доклады

| Столбец | Правило |
|---|---|
| **ID** | Стабильный ключ (`S1-08`, `P-12`, `P-J1`, `P-S2`). **Не меняйте** — по нему хранятся звёздочки участников. При перестановке меняйте «№», не ID. |
| Секция / № | Связывают доклад с полем «Доклады» в блоке |
| Фамилия, Имя, Организация, Email, Название | как в тезисах (язык любой); email можно заполнить позже |
| Длительность (мин) | пусто = 15 (секция), 30 (пленарный), 20 (юбилейный), 15 (спонсор) |
| Начало | необязательный сдвиг внутри блока |
| Статус | пусто / `отменён` / `перенесён` |
| Тематика | для пленарных: номер секции, к которой относится доклад |

### Постеры

ID вида `POST-05` тоже не меняйте. «№ стенда» можно заполнить позже.

### Изменения

Появляется на сайте как лента «Изменения в программе». Пишите дату/время и текст RU/EN — участники увидят бейдж, пока не откроют ленту.

## Что делает сайт

- Расписание по дням, параллельные секции сеткой на широком экране и карточками на телефоне.
- Полные программы секций, постеры, поиск и указатель докладчиков.
- «Моё» — звёздочки **без входа в систему**, в этом браузере. Перенос на другой телефон: кнопка «Поделиться» (`#my=S1-08,P-12,…`) или файл `.ics`.
- Русский / English (`?lang=en` открывает английский интерфейс сразу). Названия докладов показываются как в книге.
- Светлая / тёмная тема, размер шрифта A / A+ / A++.
- «Сейчас / Далее» в день конференции (часовой пояс Хабаровска). Для проверки: `?now=2026-09-22T14:30`.
- Печать (кнопка в подвале) и выгрузка всей программы в календарь.

Ограничение звёздочек: они привязаны к адресу страницы. Отметки, сделанные в локальном файле, **не появятся** на `nucleus.togudv.ru`. После публикации держите URL постоянным.

## Как отдать на сайт конференции

**Вариант A — папка.** Скопируйте содержимое `site/` на сервер (или в каталог WordPress). Подключите страницу как обычный HTML.

**Вариант B — один файл.** Отправьте `dist/nucleus2026-programme.html`. Шрифт уже внутри.

**Вариант C — iframe** (WordPress, страница «Information for Participants»):

```html
<iframe
  src="https://nucleus.togudv.ru/programme/"
  title="NUCLEUS-2026 programme"
  style="width:100%;min-height:80vh;border:0;border-radius:16px;"
></iframe>
<p><a href="https://nucleus.togudv.ru/programme/?lang=en">English programme</a></p>
```

Подставьте реальный URL, который выдаст администратор. Английская ссылка — `?lang=en`.

Локальная проверка без сервера: откройте `site/index.html`. Либо:

```text
python -m http.server 8080 --directory site
```

и зайдите на `http://127.0.0.1:8080/`.

Проверка по ссылке (GitHub Pages): [https://shadowcaramel.github.io/Conference-schedule/](https://shadowcaramel.github.io/Conference-schedule/). Каждый push в `main` обновляет эту страницу из папки `site/`. После `python tools/build.py` закоммитьте изменённые файлы в `site/`.

## Миграция из исходного Excel (один раз)

Уже выполнена. Повторная перезапись книги **уничтожит ручные правки**:

```text
python tools/migrate.py --force
```

Отчёт о спорных местах при переносе (сдвиг номеров секций относительно грида, ALL CAPS → обычный регистр, постерная сессия 16:45–18:00 23.09 и т.д.) — `data/migration-report.md`. Что ещё нужно решить с участниками (дубли, пустые аудитории, email, «председатели») — `data/inconsistencies.md`.
