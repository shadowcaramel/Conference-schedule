# ЯДРО-2026 — программа конференции

Интерактивное расписание (русский / English) для сайта [nucleus.togudv.ru](http://nucleus.togudv.ru/). Работает без сервера: достаточно открыть папку `site/` в браузере или отдать администратору один HTML-файл.

## Что смотреть участникам

- `site/index.html` — полноценный сайт (откройте файл двойным щелчком или положите всю папку `site/` на веб-сервер).
- `dist/nucleus2026-programme.html` — тот же сайт одним файлом (удобно переслать или вставить на WordPress через iframe). Собирается командой ниже.

## HTTP и HTTPS (защищённый контекст)

Живая программа на конференции — **http://nucleus.togudv.ru/timetable/**, пока без сертификата. Браузер считает страницу «защищённой» не по слову http в адресной строке, а по **контексту**:

| Как открыли | Защищённый контекст? | Что это значит для нас |
|---|---|---|
| `https://…` (GitHub Pages; `nucleus.togudv.ru` после сертификата) | да | все браузерные API, включая установку приложения |
| `http://127.0.0.1:8080/` или `http://localhost:8080/` | да | localhost браузер приравнивает к HTTPS — удобно проверять PWA и копирование ссылок |
| `http://nucleus.togudv.ru/…` | нет | Clipboard API, service worker, системная установка приложения **отсутствуют** |
| Файл `site/index.html` двойным щелчком (`file://`) | нет | то же, плюс звёздочки не совпадут с сайтом конференции |

Расписание, поиск, «Моё», печать, выгрузка `.ics`, карты — **не зависят** от HTTPS и на голом HTTP работают как обычно.

Ниже — то, что на HTTP ломалось или не существует, и как это обошли. Код смотрит на `window.isSecureContext`, а не на текст `https` в URL.

### Приложение на экран Домой (PWA)

На **HTTPS** (GitHub Pages, localhost, и когда на `nucleus.togudv.ru` включат сертификат) это полноценное PWA: Chrome/Edge предлагают «Установить», иконка на рабочем столе или на экране Домой, окно без адресной строки, офлайн-запас на случай пропажи сети.

На **HTTP** браузер *не может* поставить настоящее приложение: service worker и событие `beforeinstallprompt` требуют защищённый контекст. Решение — не притворяться приложением, а дать близкий опыт:

- `sw.js` **не регистрируется**, если контекст не защищён (иначе браузер только пишет ошибку в консоль);
- кнопка **«На экран Домой»** в подвале и подсказка на телефоне;
- пошаговая инструкция (Safari → Поделиться → На экран «Домой»; Chrome → ⋮ → Добавить на главный экран);
- в диалоге — явное предупреждение: по HTTP получится ярлык, который обычно открывает **вкладку** браузера, не отдельное окно.

Проверка полной установки: [страница на GitHub Pages](https://shadowcaramel.github.io/Conference-schedule/) (HTTPS). Локально: `python -m http.server 8080 --directory site` и `http://127.0.0.1:8080/`.

Офлайн-кэш (только после настоящей установки) **сетевой в первую очередь**: свежая `data.js` с сервера важнее вчерашней копии. Кэш нужен только если сети нет.

### Буфер обмена (ссылка на доклад)

Кнопки **«Ссылка на доклад»**, **«Ссылка на событие»** и запасной путь у **«Поделиться»** копируют URL. Современный Clipboard API (`navigator.clipboard.writeText`) на голом HTTP **не существует** — на `nucleus.togudv.ru` кнопка сначала казалась «мёртвой».

Дополнительная ловушка: карточка доклада — модальный `<dialog>`. Пока он открыт, остальная страница «инертна», и старый `document.execCommand('copy')` не срабатывает, если поле для копирования вставлено в `document.body` снаружи диалога.

Решение — функция `copyText()` в `site/app.js`, три ступени:

1. Clipboard API, если контекст защищённый (HTTPS / localhost);
2. скрытое поле **внутри открытого диалога** и `execCommand('copy')` — так работает живой HTTP-сайт;
3. если браузер запретил и это — окно `prompt` со ссылкой, чтобы скопировать вручную.

Сообщение «Ссылка скопирована» показывается тостом внутри того же диалога (иначе его не видно поверх карточки).

### «Поделиться моим расписанием» (Web Share)

Системное меню «Поделиться» (`navigator.share`) тоже обычно только в защищённом контексте. На HTTP кнопка в «Моё» сразу копирует ссылку `#my=…` тем же `copyText()`. На телефоне с HTTPS сначала предлагается системный шаринг, при отмене — снова копирование.

### iframe на WordPress

Не из‑за HTTP как такового, но рядом: из рамки чужого сайта браузер **не предлагает** установку приложения, а родительская страница может запретить доступ к буферу обмена. Решение: кнопка **«Открыть в новой вкладке»** в подсказке установки; для копирования ссылок участнику надёжнее открыть программу отдельно, не из iframe.

### Когда на сайте конференции включат HTTPS

Менять код не нужно: service worker начнёт регистрироваться, Clipboard API пойдёт первой ступенью, Chrome сможет поставить настоящее приложение.

Учтите три следствия:

- звёздочки «Моё», сделанные на **http://**nucleus…, на **https://**nucleus… **не переедут** (для браузера это другой адрес, как `file://` и сайт). Участникам — кнопка «Поделиться» или отметить заново;
- в iframe и ссылках замените `http://nucleus.togudv.ru/timetable/` на `https://…`;
- внешние ссылки (Яндекс Карты, сайты спонсоров) уже `https://`, смешанного контента из‑за них не будет.

## Как устроена правка программы

Единственный источник правды — книга **`data/programme.xlsx`**. Сетка «TimeTable» из исходного Excel больше не редактируется: расписание на сайте **собирается** из списков докладов и блоков.

Исходная книга комитета лежит в `data/original/` (архив) и в корне репозитория.

```
data/programme.xlsx  →  python tools/build.py  →  site/data.js
                                               →  dist/nucleus2026-programme.html
```

После любой правки книги:

```text
python tools/build.py
```

Обновите страницу в браузере. Если Excel держит файл открытым, сборка напишет об этом — сохраните и закройте книгу.

Проверка без записи файлов: `python tools/build.py --check`.

Нужны Python 3.10+ и пакет `openpyxl` (`pip install openpyxl`). Node.js и conda не требуются.

## Листы `programme.xlsx`

Заголовки столбцов не переименовывайте. Строки можно добавлять, удалять и переставлять. Пустая английская ячейка на сайте подменяется русской (и наоборот).

### Настройки

Название конференции, город, даты, часовой пояс (`Asia/Vladivostok`), смещение UTC (`+10:00`), ссылка на сайт, контакт, сноска под расписанием.

### Секции

Номер (`1`–`7`, `P` — пленарные), краткое и полное название RU/EN, председатель заседания на этом листе не заполняйте (у секций 1–7 комнаты и chairs меняются по слотам; chairs пишите в «Блоки»). Цвет (`blue`, `green`, `orange`, `red`, `purple`, `teal`, `pink`, `slate`), аудитория по умолчанию (оставьте пустой).

### Блоки

Одна строка — один слот расписания.

| Столбец | Что писать |
|---|---|
| Дата | `21.09.2026` или `2026-09-21` |
| Начало / Конец | `16:15` |
| Тип | только из списка: `пленарный`, `юбилейный`, `спонсор`, `секция`, `перерыв`, `обед`, `регистрация`, `открытие`, `закрытие`, `постеры`, `мероприятие` |
| Название (RU) / (EN) | для кофе и обеда можно оставить пустым — подставятся стандартные подписи |
| Секция | `1`–`7` или `P` |
| Доклады | диапазон `8-14`, одно число `12`, юбилей `Ю1`, спонсор `С2`, список `1,3,5` |
| Аудитория | код помещения: `235ц`, `библиотека`, `117л`, `315л`, `вестибюль`, `холл2`, `причал` (экскурсия), `интурист` (банкет). Сборка подставляет полные подписи RU/EN. Старый код `144ц` читается как библиотека, на сайте не показывается. Пленарные / открытие / юбилей / спонсор / закрытие / концерт — `235ц`. Не заполняйте «Секции → Аудитория»: одна секция бывает в разных залах. |
| Председатель (RU)/(EN) | председатель **этого** заседания (пленарный слот или секционное заседание). На сайте вкладка «Секции» собирает уникальные имена в шапке секции и показывает chair конкретного слота на карточке дня. Формат: инициалы и фамилия, `И. Н. Изосимов` / `I. N. Izosimov`. |
| Примечание | RU/EN |

Время каждого доклада внутри секции считается автоматически: начало блока + сумма длительностей предыдущих. Чтобы сдвинуть один доклад, заполните столбец «Начало» в листе «Доклады».

### Доклады

| Столбец | Правило |
|---|---|
| **ID** | Стабильный ключ (`S1-08`, `P-12`, `P-J1`, `P-S2`). **Не меняйте** — по нему хранятся звёздочки участников. При перестановке меняйте «№», не ID. |
| Секция / № | Связывают доклад с полем «Доклады» в блоке |
| Фамилия, Имя, Отчество, Организация, Email, Название | как в тезисах (язык любой). Отчество — отдельный столбец (пусто, если нет). Email с сайта регистрации, если удалось однозначно сопоставить |
| Длительность (мин) | пусто = 15 (секция), 30 (пленарный), 30 (юбилейный), 15 (спонсор) |
| Начало | необязательный сдвиг внутри блока |
| Статус | пусто / `отменён` / `перенесён` |
| Тематика | для пленарных: номер секции, к которой относится доклад |
| Сайт | необязательно: URL компании (для докладов спонсоров — плитка со ссылкой в карточке) |
| Логотип | необязательно: имя файла в `site/assets/sponsors/` (например `gammatech.png`) |
| Спонсор (RU) / Спонсор (EN) | необязательно: название компании на плитке |

#### Поменять два доклада местами

Порядок в сетке задаёт столбец **«№»** (и поле «Доклады» в блоке), а не порядок строк. **ID не меняйте** — по нему хранятся звёздочки участников.

1. На листе **Доклады** поменяйте у двух строк значения **«№»**. Если доклады из разных секций — поменяйте и **«Секция»**.
2. Если у кого-то заполнено **«Начало»**, поменяйте эти ячейки тоже или очистите: иначе доклад останется на старом времени.
3. Лист **Блоки** трогать не нужно, пока оба номера остаются в том же диапазоне (`8-14` и т.п.). Чтобы перенести доклад в другой слот, достаточно, чтобы его новый «№» попал в «Доклады» нужного блока.
4. Сохраните книгу и выполните `python tools/build.py`. При желании добавьте строку на лист **Изменения**.

### Постеры

ID вида `POST-05` тоже не меняйте. «№ стенда» можно заполнить позже. «Отчество» и «Статус» — как у докладов (статус: пусто / `отменён` / `перенесён`).

### Изменения

Появляется на сайте как лента «Изменения в программе». Пишите дату/время и текст RU/EN — участники увидят бейдж, пока не откроют ленту.

## Что делает сайт

- Расписание по дням, параллельные секции сеткой на широком экране и карточками на телефоне.
- Полные программы секций, постеры, поиск и указатель докладчиков.
- «Моё» — звёздочки **без входа в систему**, в этом браузере. Перенос на другой телефон: кнопка «Поделиться» (`#my=S1-08,P-12,…`) или файл `.ics`.
- Русский / English (`?lang=en` открывает английский интерфейс сразу). Названия докладов показываются как в книге.
- Светлая / тёмная тема, размер шрифта A / A+ / A++.
- «Сейчас / Далее» в день конференции (часовой пояс Хабаровска). Для проверки: `?now=2026-09-22T14:30`.
- Печать (кнопка в подвале) и выгрузка всей программы в календарь.
- Справка для новых участников: при первом заходе — короткий гид (разделы, дни, лента/сетка, «Моё»), кнопка **«?»** в шапке запускает его снова.

Ограничение звёздочек: они привязаны к адресу страницы. Отметки с `file://` или с `http://` **не появятся** на `https://` той же машины (и наоборот). После публикации и после включения HTTPS держите URL постоянным. См. раздел «HTTP и HTTPS».

### Флаги в `site/app.js`

В начале файла выключатели на весь сайт (не настройка пользователя):

```js
const HAPTICS_ON = true; // виброотклик на телефоне
const TOUR_ON = true;    // гид для новых участников и кнопка «?»
const OVERVIEW_SECTION_SORT = 'room'; // сетка: порядок параллельных секций
```

`HAPTICS_ON` / `TOUR_ON`: поставьте `false`, чтобы отключить функцию у всех, не удаляя код. Сохранённый прогресс гида (`localStorage` ключ `nucleus2026:tour`) не сбрасывается: если снова включить `TOUR_ON`, прошедшие гид не увидят его автоматически.

`OVERVIEW_SECTION_SORT` действует только на вид «Сетка» (и на её печать). Лента не меняется.

- `'room'` (по умолчанию) — колонки слева направо: библиотека → актовый зал → 117л → 315л.
- `'section'` — прежний порядок по номерам секций S1…S7.

## Как отдать на сайт конференции

Живая программа: [http://nucleus.togudv.ru/timetable/](http://nucleus.togudv.ru/timetable/). На FTP уходит **только** содержимое `site/` (без Excel и исходников). Загрузка **по запросу**, не после каждой правки: сначала смотрите локально, потом публикуйте.

```text
python tools/deploy.py --dry-run   # что изменилось, без загрузки
python tools/deploy.py             # залить файлы с другим размером
python tools/deploy.py --build     # сначала python tools/build.py, затем FTP
```

Учётные данные — в `.ftp.env` (скопируйте `.ftp.env.example`, файл в git не попадает). В Cursor достаточно сказать «выложи на сайт» / «deploy timetable».

**Один файл.** Вместо папки можно отправить `dist/nucleus2026-programme.html` (шрифт уже внутри).

**iframe** (WordPress, страница «Information for Participants»):

```html
<iframe
  src="http://nucleus.togudv.ru/timetable/"
  title="NUCLEUS-2026 programme"
  style="width:100%;min-height:80vh;border:0;border-radius:16px;"
></iframe>
<p><a href="http://nucleus.togudv.ru/timetable/?lang=en">English programme</a></p>
```

Локальная проверка без сервера: откройте `site/index.html`. Либо:

```text
python -m http.server 8080 --directory site
```

и зайдите на `http://127.0.0.1:8080/`.

Проверка по ссылке (GitHub Pages): [https://shadowcaramel.github.io/Conference-schedule/](https://shadowcaramel.github.io/Conference-schedule/). Каждый push в `main` обновляет эту страницу из папки `site/`. После `python tools/build.py` закоммитьте изменённые файлы в `site/`.

## Миграция из исходного Excel (один раз)

Уже выполнена. Повторная перезапись книги **уничтожит ручные правки**:

```text
python tools/migrate.py --force
```

Отчёт о спорных местах при переносе (сдвиг номеров секций относительно грида, ALL CAPS → обычный регистр, постерная сессия 16:45–18:00 23.09 и т.д.) — `data/migration-report.md`. Что ещё нужно решить с участниками — `data/inconsistencies.md`.
