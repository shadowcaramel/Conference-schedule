# ЯДРО-2026 / NUCLEUS-2026

Программа конференции, которую можно открыть в браузере: дни, параллельные секции, поиск, своё расписание. Русский и английский интерфейс, сервер и вход не нужны.

На конференции сайт жил здесь: [nucleus.togudv.ru/timetable](http://nucleus.togudv.ru/timetable/). Эта ветка `dev` туда больше не заливается — там остаётся то, что стояло во время ЯДРО-2026. Снимок того состояния — тег [NUCLEUS-2026](https://github.com/shadowcaramel/Conference-schedule/releases/tag/NUCLEUS-2026) на `main` (тот же коммит подписан тегом `ЯДРО-2026`).

Как открыть:

- Сначала `python tools/build.py`: файл `site/data.js` собирается и в git не хранится. Без сборки страница не найдёт программу.
- `site/index.html` — весь сайт. После сборки файл можно открыть двойным щелчком или положить папку `site/` на любой веб-сервер.
- `dist/nucleus2026-programme.html` — тот же сайт одним файлом (удобно переслать или вставить во фрейм). Его собирает та же команда.

Публичная копия этой ветки: [GitHub Pages](https://shadowcaramel.github.io/Conference-schedule/). Push в `dev` сначала проверяет JSON, гоняет тесты и собирает `site/data.js`, и только потом выкладывает папку `site/`. Подписи `?v=` в `index.html` и имя кэша в `sw.js` тоже пишет сборка, их не коммитят.

## Что на сайте

- Расписание по дням. На широком экране параллельные секции стоят сеткой, на телефоне — карточками.
- Программы секций, постеры, поиск, указатель докладчиков.
- «Моё» — звёздочки без аккаунта, только в этом браузере. На другой телефон их увозят кнопкой «Поделиться» (ссылка вида `#my=S1-08,P-12,…`) или файлом `.ics`.
- Язык переключается в интерфейсе. `?lang=en` сразу открывает английский. Названия докладов остаются как в книге.
- Светлая и тёмная тема, размер шрифта A / A+ / A++.
- В дни конференции сверху «Сейчас / Далее» по хабаровскому времени. Проверить вёрстку можно так: `?now=2026-09-22T14:30`.
- Печать из подвала и выгрузка всей программы в календарь.
- Короткий гид при первом заходе. Кнопка «?» в шапке запускает его снова.

Звёздочки привязаны к адресу страницы. Отметки, сделанные через `file://` или через `http://`, на `https://` той же машины не появятся: для браузера это разные сайты.

## HTTP и HTTPS

Живая программа конференции открыта по HTTP, без сертификата: [http://nucleus.togudv.ru/timetable/](http://nucleus.togudv.ru/timetable/). Расписание, поиск, «Моё», печать, `.ics` и карты от этого не зависят и на голом HTTP работают.

Браузер смотрит не на буквы `https` в адресной строке, а на то, считает ли он страницу защищённой. Код проверяет `window.isSecureContext`.

| Как открыли | Страница защищённая? | Что это значит |
|---|---|---|
| `https://…` — GitHub Pages; `nucleus.togudv.ru`, когда появится сертификат | да | доступны установка приложения и остальные браузерные API |
| `http://127.0.0.1:8080/` или `http://localhost:8080/` | да | localhost браузер приравнивает к HTTPS, удобно проверять приложение и копирование ссылок |
| `http://nucleus.togudv.ru/…` | нет | нет Clipboard API, service worker и системной установки |
| файл `site/index.html` двойным щелчком (`file://`) | нет | то же самое, и звёздочки не совпадут с сайтом конференции |

**Экран «Домой».** На HTTPS это приложение: Chrome и Edge предлагают «Установить», иконка на рабочем столе или на экране, окно без адресной строки, запасная копия если пропадёт сеть. На HTTP браузер так сделать не может: service worker и событие `beforeinstallprompt` требуют защищённую страницу. `sw.js` там не регистрируется, иначе в консоли только ошибка. Вместо этого в подвале кнопка «На экран Домой» и шаги: Safari → Поделиться → На экран «Домой»; Chrome → ⋮ → Добавить на главный экран. В диалоге прямо сказано: по HTTP получится ярлык, который обычно открывает вкладку, а не отдельное окно.

Полную установку можно проверить на [GitHub Pages](https://shadowcaramel.github.io/Conference-schedule/). Локально: `python -m http.server 8080 --directory site`, затем `http://127.0.0.1:8080/`.

Офлайн-кэш включается только после настоящей установки и сначала идёт в сеть. Свежий `data.js` важнее вчерашней копии. Кэш нужен, когда сети нет.

**Ссылка на доклад.** Кнопки «Ссылка на доклад», «Ссылка на событие» и запасной путь у «Поделиться» копируют URL. На голом HTTP современного Clipboard API нет, поэтому на сайте конференции кнопка сначала казалась мёртвой. Карточка доклада — это открытый `<dialog>`. Пока он открыт, страница под ним «заморожена», и старый `document.execCommand('copy')` не срабатывает, если поле для копирования вставлено в `document.body` снаружи диалога.

`copyText()` в `site/app.js` идёт по ступенькам:

1. Clipboard API, если страница защищённая (HTTPS или localhost).
2. Скрытое поле внутри открытого диалога и `execCommand('copy')` — так работает живой HTTP-сайт.
3. Если браузер запретил и это — окно `prompt` со ссылкой, чтобы скопировать вручную.

Надпись «Ссылка скопирована» показывается внутри того же диалога, иначе её не видно поверх карточки.

**Поделиться своим расписанием.** Системное меню `navigator.share` тоже обычно только на защищённой странице. На HTTP кнопка в «Моё» сразу копирует ссылку `#my=…` через тот же `copyText()`. На телефоне с HTTPS сначала предлагается системное меню, а если его закрыть — снова копирование.

**Фрейм на WordPress.** Дело не в HTTP как таковом. Из чужой рамки браузер не предлагает установить приложение, а страница-родитель может запретить доступ к буферу. В подсказке установки есть «Открыть в новой вкладке». Ссылку надёжнее копировать, открыв программу отдельно, не из фрейма.

Когда на сайте конференции включат HTTPS, код менять не нужно: service worker зарегистрируется, копирование пойдёт первой ступенью, Chrome сможет поставить настоящее приложение. Три вещи всё же всплывут:

- звёздочки, поставленные на **http://**nucleus…, на **https://**nucleus… не переедут (для браузера это другой адрес, как `file://` и сайт). Участнику остаётся «Поделиться» или отметить заново;
- во фреймах и ссылках `http://nucleus.togudv.ru/timetable/` нужно заменить на `https://…`;
- внешние ссылки (Яндекс Карты, сайты спонсоров) уже на `https://`, из-за них смешанного содержимого не будет.

## Что сознательно не делали

- QR-код на стойку регистрации.
- Тезисы и PDF по докладам.
- Общее «Моё» между телефонами через сервер: для этого нужен вход.
- Редактор на сервере конференции. Локальный редактор описан в конце этого файла; на nucleus.togudv.ru он ничего не заливает. Вид JSON по-прежнему задаёт `tools/dataio.py`, и CI его проверяет.

Шрифт [Onest](https://fonts.google.com/specimen/Onest) ([simpals/onest](https://github.com/simpals/onest)) — SIL Open Font License, файлы в `site/assets/fonts/`. Иконки — встроенные SVG [Lucide](https://lucide.dev/).

## Как править программу

Единственный источник правды — JSON в **`data/`**. Поля и правила id — в [docs/data-model.md](docs/data-model.md). Сайт по-прежнему читает `window.PROGRAMME` из `site/data.js`. Этот файл собирается и в git не входит.

```text
data/*.json  →  python tools/build.py  →  site/data.js
                                     →  dist/nucleus2026-programme.html
```

После правки JSON:

```text
python tools/build.py
```

Обновите страницу. Проверка без записи: `python tools/build.py --check`. Схема и связи: `python tools/validate.py`. Канонический вид файлов: `python tools/dataio.py --check`. Сборка принимает `--data data/`: вторая конференция — это вторая папка.

Нужны Python 3.10+ и зависимости из `pyproject.toml` (`pip install ".[dev]"`). Node.js не нужен.

На [nucleus.togudv.ru](http://nucleus.togudv.ru/timetable/) из этой ветки ничего не выкладывается. Смотреть результат локально (после сборки) или на GitHub Pages.

Локально: `python tools/build.py`, затем `site/index.html` или

```text
python -m http.server 8080 --directory site
```

и `http://127.0.0.1:8080/`.

GitHub Pages: [https://shadowcaramel.github.io/Conference-schedule/](https://shadowcaramel.github.io/Conference-schedule/). Push в `dev` запускает проверку и сборку, затем выкладку. `site/data.js` и подписи `?v=` коммитить не нужно.

Один файл вместо папки — `dist/nucleus2026-programme.html` (шрифт уже внутри). Для WordPress, это адрес уже выложенной конференции, не этой ветки:

```html
<iframe
  src="http://nucleus.togudv.ru/timetable/"
  title="NUCLEUS-2026 programme"
  style="width:100%;min-height:80vh;border:0;border-radius:16px;"
></iframe>
<p><a href="http://nucleus.togudv.ru/timetable/?lang=en">English programme</a></p>
```

### Файлы `data/`

| Файл | Что это |
|---|---|
| `conference.json` | Названия, город, даты, часовой пояс, языки, длительности по умолчанию |
| `tracks.json` | Секции `1`–`7` и `P`: названия и цвет |
| `rooms.json` | Залы и подписи, которые видит сайт |
| `sessions.json` | Слоты `B001`–`B084` |
| `contributions.json` | Доклады и постеры одним списком |
| `people.json` | Авторы и председатели |
| `organizations.json` | Аффилиации и спонсоры (`url`, `logo`) |
| `resources.json` | Ссылки на слайды и видео. Пока пусто, сами файлы в репозиторий не кладут |
| `changes.json` | Лента «Изменения в программе» |

Двуязычный текст — `{ "ru", "en" }`. Название доклада обычно одна строка. Имя — `family`, `given`, `patronymic`.

Часы доклада в JSON не пишут. У вклада есть место в слоте (`session_id`, `order`), `duration_min` и необязательный `start`, если начало нужно приколоть. Сборка считает время. Смещение UTC тоже не хранится: оно выводится из `timezone` (`Asia/Vladivostok`).

**Id не менять.** `S1-08`, `P-12`, `P-J1`, `P-S1`, `POST-05` и остальные id вкладов — это звёздочки и ссылки `#my=`. Id слотов `B001`–`B084` тоже постоянные. Новым записям — новые id, без перенумерации.

Поменять два доклада местами: поменяйте `order` и список `contribution_ids` у сессий. Сами `id` не трогайте. Чтобы сдвинуть один доклад внутри слота, заполните `start`. Постеру можно дописать `board`. Статус: `ok`, `cancelled`, `moved`.

Председатель слота — ссылка на человека плюс строка `label`, как она стояла в программе. Один человек бывает подписан по-разному (`Вефасев Л. Д.` и `Л. Д. Вефасев`).

Книга Excel больше не источник. Она остаётся на `main` и в теге `NUCLEUS-2026`. `tools/import_xlsx.py` — одноразовый перевод; кто с кем сопоставился, написано в `data/import-report.md`.

### Что не пройдёт проверку

Ошибки останавливают сборку и GitHub Pages. Среди них: два слота в одном зале или на одной секции с пересечением по времени. Раньше это были предупреждения. Стык `10:00–10:30` и `10:30–11:00` пересечением не считается.

Предупреждения сборку не останавливают. Слот секции, у которого доклады кончаются не тогда, когда записан конец. Вклад без слота. Пустой английский у двуязычного названия. Один человек в двух вкладах в одно время. Председатель, который в это же время выступает в другом слоте. Выступление в своём заседании предупреждением не является.

### Выключатели в `site/app.js`

В начале файла — флаги на весь сайт, это не настройка посетителя:

```js
const HAPTICS_ON = true; // виброотклик на телефоне
const TOUR_ON = true;    // гид для новых участников и кнопка «?»
const OVERVIEW_SECTION_SORT = 'room'; // сетка: порядок параллельных секций
```

`HAPTICS_ON` и `TOUR_ON`: `false` выключает функцию у всех, код удалять не нужно. Прогресс гида (ключ `nucleus2026:tour` в `localStorage`) не сбрасывается. Если снова включить `TOUR_ON`, те, кто гид уже прошёл, сами его не увидят.

`OVERVIEW_SECTION_SORT` влияет только на вид «Сетка» и на её печать. Лента не меняется.

- `'room'` (по умолчанию) — колонки слева направо: библиотека → актовый зал → 117л → 315л.
- `'section'` — порядок по номерам секций S1…S7.

## Редактор

Локальный редактор слушает только `127.0.0.1` и ничего не выкладывает на nucleus.togudv.ru.

```text
cd editor
npm install
npm run build
cd ..
python tools/edit.py
```

Открыть http://127.0.0.1:8765/. Сетка расписания только для чтения; у вклада есть форма. Поля языков идут в порядке `conference.languages`, id менять нельзя. Проверка — та же, что у `tools/validate.py`; запись идёт через `tools/dataio.py`. Pull request в `dev` собирает редактор, а GitHub Pages по-прежнему публикует только папку `site/`.
